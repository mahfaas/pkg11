Colorimeter

RGB · CMYK · HSV · HLS · XYZ · L*a*b* — every conversion is computed here from first principles: no color-management library is used, the RGB↔XYZ matrix is rebuilt from primaries and white point whenever the illuminant changes.

Формулы и допущения

RGB → XYZ

Матрица не захардкожена: она строится из хроматичностей праймериз sRGB (R 0.6400/0.3300, G 0.3000/0.6000, B 0.1500/0.0600) и точки белого выбранного стандарта освещения методом Брюса Линдблума (решение M·S=W, затем масштабирование столбцов на S). При смене освещения меняется только W — матрица пересчитывается на лету.

Xr=xr/yr, Zr=(1-xr-yr)/yr (аналогично для G,B) M = [[Xr,Xg,Xb],[1,1,1],[Zr,Zg,Zb]] S = M⁻¹ · [Xw,Yw,Zw]ᵀ N = [Xr·Sr, Xg·Sg, Xb·Sb; Sr,Sg,Sb; Zr·Sr,Zg·Sg,Zb·Sb] [X,Y,Z] = N · [Rlin,Glin,Blin], Rlin из sRGB через гамма-функцию

XYZ ↔ L*a*b*

f(t) = t^(1/3) если t > (6/29)³ f(t) = t/(3·(6/29)²) + 4/29 иначе L* = 116·f(Y/Yn) − 16 a* = 500·(f(X/Xn) − f(Y/Yn)) b* = 200·(f(Y/Yn) − f(Z/Zn))

Xn,Yn,Zn — координаты выбранного опорного белого (тот же пересчитываемый набор, Yn=100).

RGB ↔ HSV / HLS

Стандартные секторные формулы по max/min каналов gamma-corrected RGB (0..1), без изменений.

RGB → CMYK

C0=1−R, M0=1−G, Y0=1−B (0..1) GCR: K=min(C0,M0,Y0)·amount; C=(C0−K)/(1−K), ... UCR: K=min(C0,M0,Y0)·amount; C=max(0, C0−K), ... (без ренормировки — чернее в тенях, менее «вымыты» света) CMYK→RGB: R=(1−C)(1−K), ...

GCR заменяет серую составляющую чёрным по всему диапазону тонов; UCR — только убирает часть CMY, не перераспределяя её в K пропорционально, что даёт более узкую, теневую коррекцию. Ползунок «сила» — доля K, которая реально применяется (0–100%).

Выход за цветовой охват (XYZ/LAB → RGB)

Clipping: v' = clamp(v, 0, 1) Scaling: lo=min(0,R,G,B), hi=max(1,R,G,B); v' = (v−lo)/(hi−lo)

Предупреждение показывается, если хотя бы один линейный канал до коррекции выходил за [0,1].
