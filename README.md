# Цветовые модели (MVC)

Веб-приложение для интерактивного перевода цветов между моделями RGB, CMYK, HSV, HLS, XYZ, LAB.  
Лабораторная работа №1, дисциплина ПКГ. Вариант №1: RGB ↔ LAB ↔ CMYK.

**Ссылка на проект:** [https://mahfaas.github.io/pkg11/](https://mahfaas.github.io/pkg11/)

---

## Структура проекта

```
├── index.html          # Главная страница (View — разметка)
├── css/
│   └── styles.css      # Стили интерфейса
├── js/
│   ├── model.js        # Model — математика преобразований цветов
│   ├── view.js         # View — управление DOM и отрисовка элементов
│   ├── controller.js   # Controller — связка Model и View
│   └── tests.js        # Автоматические тесты математики
└── README.md
```

## Возможности

- **6 цветовых моделей:** RGB, CMYK, HSV, HLS, XYZ, LAB — все отображаются одновременно.
- **3 способа задать цвет:** ползунок, числовое поле, графическая палитра (HSV-квадрат + Color Picker).
- **Динамические градиенты** на ползунках — фон показывает доступный цвет при сдвиге.
- **Стандарты освещения:** D65, D50, E — матрица RGB↔XYZ пересчитывается на лету.
- **Алгоритмы CMYK:** GCR (Замена серой компоненты) и UCR (Удаление подложечного цвета).
- **Обработка выхода за гамму:** Clipping (обрезание) и Scaling (масштабирование).
- **Автотесты:** при загрузке страницы проверяется корректность математики (результат виден в интерфейсе и в консоли F12).
- **Тёмная/светлая тема.**

## Архитектура

Проект построен на паттерне **MVC**:

| Файл | Роль |
|---|---|
| `model.js` | Чистая математика. Никакого DOM. |
| `view.js` | Только отрисовка интерфейса. Никакой математики. |
| `controller.js` | Слушает события, передаёт данные между Model и View. |

## Запуск

Просто откройте `index.html` в браузере — установка ничего не требуется.
