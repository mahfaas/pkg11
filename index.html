Формулы и архитектура

Паттерн «Мост» (Bridge)

Абстракция: ColorModel — публичный API (геттеры/сеттеры).
Реализация: ColorModelImpl — математика и внутреннее состояние.
Если заменить реализацию (например, на другой движок), абстракция остаётся без изменений.

Паттерн «Слушатель» (Observer)

Издатель: ColorModel — испускает событие colorChanged через ColorEventBus.
Подписчик: Controller — вызывает refreshAll() при каждом изменении цвета.
Model не знает о View и Controller.

RGB ↔ XYZ (D65, метод Линдблума)

Матрица строится из хроматичностей праймериз sRGB: r:(0.64,0.33) g:(0.30,0.60) b:(0.15,0.06) и белой точки D65 (x=0.31271, y=0.32902). Применяется гамма-коррекция sRGB: γ→lin: c ≤ 0.04045 → c/12.92, иначе ((c+0.055)/1.055)^2.4 lin→γ: c ≤ 0.0031308 → c*12.92, иначе 1.055·c^(1/2.4) − 0.055

RGB ↔ HLS (секторные формулы)

Нормированный RGB → [0,1] max = max(R,G,B), min = min(R,G,B), d = max−min L = (max+min)/2 S = d / (1 − |2L−1|) (при d≠0) H — угол в зависимости от доминирующего канала

График МКО CIE 1931

Диаграмма хроматичности CIE 1931 xy строится на основе таблицы спектрального локуса. Каждый пиксель внутри локуса окрашивается по координатам xy (при Y=1) через матрицу XYZ→sRGB. Текущий цвет отображается маркером; пунктир соединяет его с белой точкой D65.
